# 关键词策略

本项目的关键词体系参考恨也迷人"量大管饱"的切片风格：触发条件宽松、覆盖面广、能用梗词捕获"其他主播提及相关话题"的片段。

## 层级设计

| 层级 | 匹配类型 | 示例 | 触发条件 |
|------|----------|------|----------|
| **T1 核心触发** | 精确匹配（大小写不敏感） | `星瞳` `XingTong` `XT` | 命中即触发 |
| **T2 关联触发** | 模糊匹配（相似度 ≥ 阈值） | `小星星` `瞳子` `瞳宝` `星瞳酱` | 命中即触发 |
| **T3 梗/衍生触发** | 精确匹配 + 联合窗口 | `腾讯大小姐` `CDD` `虚无` `云之彼端` | 需与 T1/T2 在 30 秒窗口内联合出现 |
| **T4 否定词** | 精确匹配 | `不是星瞳` `星瞳的黑称` | 命中时屏蔽本次检测 |

## 检测流程

```
文本进入 40 字符滑动窗口
  ├─ T4 否定词命中？ ──────────── 是 → 不触发
  ├─ T1 精确命中？ ────────────── 是 → 触发（记录联合记录）
  ├─ T2 模糊命中？ ────────────── 是 → 触发（记录联合记录）
  └─ T3 梗词命中且窗口内有 T1/T2 记录？ → 触发
```

- **T1/T2 命中记录**保留 30 秒（`t3_cooccur_window`），供 T3 联合判断；
- **模糊匹配**：在滑动窗口内取与关键词等长的子串，计算相似度（基于最长公共子序列的比率，近似 Python `difflib.SequenceMatcher.ratio`），达到 `t2_threshold`（默认 0.75）即命中；
- **否定词优先**：同一窗口内出现 T4 词时，T1/T2/T3 全部失效。

## 状态机

```
触发(冷却通过)          停止延迟内无命中
    ┌────────┐  ──────▶  ┌───────────┐  ──────▶  ┌───────┐
    │  IDLE  │           │ RECORDING  │           │ IDLE  │
    └────────┘  ◀──────  └───────────┘           └───────┘
           冷却期后再次触发         片段合并输出
```

- **停止延迟**（`stop_delay_seconds`，默认 120s）：关键词最后出现后，等待 N 秒停止录制。越短切片越多越碎片化（"量大管饱"），越长越完整；
- **冷却时间**（`cooldown_seconds`，默认 5s）：停止后 N 秒内的再次触发被忽略，避免同一话题频繁启停。

## 热词注入

将关键词注入 ASR 热词表可显著提升识别准确率（权重 1-5）：

```yaml
asr:
  hotwords:
    星瞳: 5        # T1 核心词给最高权重
    小星星: 5
    瞳子: 4        # T2 关联词
    瞳宝: 4
    腾讯大小姐: 3  # T3 梗词
    CDD: 3
```

## 示例配置

```yaml
keyword:
  stop_delay_seconds: 120
  cooldown_seconds: 5
  t2_threshold: 0.75
  t3_cooccur_window: 30.0
  t1: ["星瞳", "XingTong", "XT"]
  t2: ["小星星", "瞳子", "瞳宝", "星瞳酱"]
  t3: ["腾讯大小姐", "CDD", "虚无", "云之彼端", "深月的风吟鸟唱", "邻家女孩", "瞳工"]
  t4: ["不是星瞳", "星瞳的黑称"]
```
