# 监控面板

hymREC 内置一个网页控制台，随进程一起启动，默认地址 `http://127.0.0.1:8080`。前端资源通过 `go:embed` 编进二进制，不需要安装 Node，也不需要单独部署。

## 启用与关闭

```yaml
web:
  enabled: true               # 是否启动监控面板
  listen: 127.0.0.1:8080      # 默认只监听本机回环地址
```

命令行可以覆盖配置：

```bash
./hymREC -web-addr 0.0.0.0:8080   # 允许局域网访问
./hymREC -no-web                  # 关闭面板，只保留录制
```

::: warning 访问控制

面板可以启停服务、修改关键词、手动切片，**默认只监听回环地址**。改成 `0.0.0.0` 暴露到局域网或公网前，请自行在反向代理层加认证。端口被占用时面板会启动失败并记录日志，录制服务不受影响。

:::

## 面板内容

| 区域 | 内容 |
|------|------|
| 状态卡片 | 直播间（房间号/标题/开播状态）、运行时长、视频缓冲（分段数/覆盖时长/最新分段）、录制状态（触发来源/已录时长/停止延迟）、语音识别（引擎/最后识别文本）、弹幕（连接状态/窗口命中数）、切片（数量/总大小） |
| 事件流 | 会话开始/结束、触发、切片产出、流地址刷新、缓冲重启与错误，实时推送 |
| 切片列表 | 按触发时间倒序，显示来源、大小、文件名，可直接下载 |
| 日志 | 与终端一致的结构化日志，可按级别过滤、跟随滚动 |
| 设置抽屉 | 直播间、关键词 T1-T4、触发节奏与弹幕密度参数 |

## 控制能力

| 操作 | 说明 |
|------|------|
| 启动 / 停止 | 停止时会等当前录制合并完切片再退出监听 |
| 手动切片 | 立即进入录制态；仅在直播会话进行中且空闲时可用 |
| 结束录制 | 立刻收尾当前录制并产出切片 |
| 应用（实时生效） | 关键词、停止延迟、冷却、T2 阈值、T3 窗口、弹幕关键词/阈值/窗口立即生效 |
| 应用并重启 | 同时切换直播间（`room_id`），按新配置重建流水线 |

::: tip 改动范围

在线设置只影响本次运行，**不会写回 `config.yaml`**；`room_id`、`danmaku.enabled` 等需要重建流水线的字段会提示"重启生效"。弹幕开关与确认延迟目前只能在配置文件里改。

:::

## 实时推送

面板通过 Server-Sent Events（`GET /api/events`）接收三类消息：

- `status`：完整状态快照，每秒一次；
- `event`：触发/切片/会话等事件，实时；
- `log`：结构化日志，实时。

连接断开时浏览器会自动重连，面板同时保留 3 秒一次的状态轮询兜底，避免界面停在旧数据。

## HTTP API

面板的所有能力都走 HTTP，可脚本化：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/status` | 当前状态快照 |
| GET | `/api/events` | SSE 实时事件流 |
| GET | `/api/logs?limit=200` | 最近日志 |
| GET | `/api/clips` | 切片列表 |
| GET | `/api/clips/{name}` | 下载切片（仅输出目录内的 `.ts`/`.mp4`） |
| GET | `/api/settings` | 当前生效的规则 |
| POST | `/api/settings` | 应用规则（请求体为 `keyword` + `danmaku` 两组字段） |
| POST | `/api/control/start` | 启动录制服务 |
| POST | `/api/control/stop` | 停止录制服务 |
| POST | `/api/control/restart` | 重启服务，可带 `{"room_id": 123}` |
| POST | `/api/control/trigger` | 手动触发一次录制 |
| POST | `/api/control/stop-recording` | 结束当前录制并产出切片 |

示例：

```bash
curl -s http://127.0.0.1:8080/api/status | jq '.service, .buffer'
curl -s -X POST http://127.0.0.1:8080/api/control/trigger
curl -s -X POST -H 'Content-Type: application/json' \
  -d '{"room_id": 21452505}' http://127.0.0.1:8080/api/control/restart
```

## 安全边界

- 默认绑定 `127.0.0.1`；
- 状态变更请求校验 `Origin`，跨站 POST 直接拒绝（防 CSRF）；
- 切片下载只允许输出目录内的 `.ts`/`.mp4` 文件名，`../` 之类路径一律 404；
- 响应带 `Content-Security-Policy`、`X-Content-Type-Options: nosniff` 等安全头。
