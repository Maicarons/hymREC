# 常见问题

### 启动报错 `启动 ffmpeg 失败（请确认已安装并加入 PATH）`

未安装 ffmpeg 或不在 PATH 中。安装 ffmpeg 并确保 `ffmpeg -version` 可执行，或在配置中指定 `recorder.ffmpeg_path`。

### 提示"主播未开播或暂无可用流地址"

1. 确认 `room_id` 正确（支持短号，会自动解析真实房间号）；
2. 确认主播确实在直播中；
3. B 站对异常请求可能返回风控，确认网络环境正常。

### 一直显示"尚未开播，等待中"

系统默认 60 秒轮询一次开播状态（`live_check_interval`），开播后最多等待一个轮询周期才会检测到。

### 关键词命中但没有产出切片

1. 检查日志中是否有 `[触发]` 与 `[切片完成]` 记录；
2. `[切片完成]` 提示"未找到可用的缓冲分段"时，说明触发时刻的视频缓冲为空——回溯窗口（`ring_buffer_seconds`）比程序启动时长还长，或缓冲分段被 `video_keep_minutes` 提前清理；
3. ffmpeg concat 失败时检查 stderr 日志。

### 切片只有视频没有声音

视频缓冲使用 `-c copy` 原样复制直播流，若 B 站流音轨异常（静音、编码特殊）可能导致无声。可尝试用播放器确认原始流是否有声。

### 弹幕没有触发录制

1. 确认 `danmaku.enabled: true`；
2. 检查日志是否有"弹幕认证成功"；
3. 弹幕关键词列表（`danmaku.keywords`）是否与直播内容匹配；
4. 密度阈值（`density_threshold`）是否过高。

### ASR 无识别结果

1. 确认 FunASR 服务可访问（`endpoint` 地址），可先用浏览器/客户端连一下 ws 地址；
2. 查看日志中是否有 ASR 错误（`level=DEBUG` 开启 debug 日志）；
3. 确认热词表在 YAML 中为普通 map，不要手动加引号。

### 录制一段时间后"音频流中断，等待重连"

直播流长时间运行可能断流。系统会等待 `stream_retry_delay` 后自动重建采集器；若频繁中断，检查网络稳定性。

### 多直播间监控

每个直播间运行一个独立实例（`-room <房间号>`），输出目录分开配置。
