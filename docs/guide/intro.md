# 简介

**hymREC**（恨也迷人风格录制系统）是一个用 Go 编写的 B 站直播关键词触发录制工具。它持续监控目标直播间，当语音识别（ASR）文本命中关键词、或弹幕密度达到阈值时，自动产出包含关键词前 90 秒上下文的视频切片，供后续 FFmpeg 剪辑（加片头、断章取义）使用。

## 设计动机

本项目的关键词策略参考了虚拟主播切片人**恨也迷人**的切片风格——"量大管饱也有爆点"：

- **量大管饱**：触发条件宽松、关键词覆盖面广，任何直播间提及相关内容都值得录制；
- **断章取义**：需要捕获关键词出现**之前**的上下文（回溯窗口从常规 60 秒扩展到 90 秒），以便剪辑时截取有戏剧效果的片段；
- **关联外溢**：不仅切主播本人的直播，其他主播提及相关话题（T3 梗词）也应触发。

## 核心特性

| 特性 | 说明 |
|------|------|
| 层级关键词 | T1 精确 / T2 模糊（相似度阈值）/ T3 梗词联合 / T4 否定屏蔽 |
| 视频回溯 | ffmpeg 按 10 秒分段持续缓冲直播流，触发后自动提取回溯片段并 concat 合并 |
| 弹幕辅助触发 | WebSocket 实时监听弹幕，30 秒窗口内含关键词弹幕达到阈值即触发（延迟确认防误触） |
| 流式 ASR | 内置 FunASR WebSocket 客户端，支持热词表注入（权重 1-5）提升识别准确率 |
| 静音检测 | 能量阈值 VAD，静音段跳过 ASR，节省计算资源 |
| 断线自愈 | 音频采集与视频缓冲均支持自动重连 |

## 技术栈

- **语言**：Go（标准库 + gorilla/websocket + brotli 解压）
- **媒体处理**：ffmpeg（音频抽取、视频分段、片段合并）
- **语音识别**：FunASR（Paraformer-zh-streaming），通过 WebSocket 接入
- **文档**：VitePress

## 使用场景

1. 录制虚拟主播（或任意 B 站主播）直播中提及特定话题的片段；
2. 为切片工作提供"断章取义"所需的原始素材（含触发前 90 秒）；
3. 多直播间监控（每个房间一个实例）。
